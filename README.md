## 📖 Overview

**Quimail PRO** is a cutting-edge, AI-powered email ID generator that creates professional, memorable email addresses with an intelligent scoring system and realistic inbox preview. Built with a stunning cyberpunk glassmorphism UI, it's perfect for professionals, developers, and creatives.

### Why Quimail PRO?

- 🎯 **Smart Generation** - AI-powered pattern matching with 20+ variations
- 📊 **Quality Scoring** - Each email gets a 0-100% professional score
- 👁️ **Live Preview** - Realistic inbox-style email preview
- 🎨 **Beautiful UI** - Cyberpunk glassmorphism design
- 🚀 **Zero Dependencies** - Runs on pure Python + Tkinter

## 🚀 Installation

### Prerequisites
- Python 3.7 or higher
- Tkinter (included with Python)

### Quick Start

```bash
# Clone the repository
git clone https://github.com/yourusername/quimail-pro.git

# Navigate to directory
cd quimail-pro

# Run the application
python quimail_pro.py
```

Android (Pydroid 3)

1. Install Pydroid 3 from Play Store
2. Copy quimail_pro.py to your device
3. Open with Pydroid 3
4. Press ▶️ Run

No pip install required! 🎉

Basic Usage

1. Enter Your Details
   ```

   Last Name: Doe
   ```

   · Browse generated emails
   · Click to preview in inbox view

   · 🔄 Refresh - Regenerate
